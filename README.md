# 🎓 CampusOS

A modern institutional management platform that streamlines academic workflows for students, teachers, and administrators through a centralized web application.

🌐 **Live Demo:** https://campus-os-henna.vercel.app/

---

## ✨ Features

### 👨‍🎓 Student
- Register & Login
- View Courses
- Submit Assignments
- View Grades
- Access Study Materials
- Pay Fees
- Raise Complaints
- View Campus Events

### 👩‍🏫 Teacher
- Create Courses
- Create Assignments
- Upload Study Materials
- Review Student Submissions
- Grade Assignments

### 👨‍💼 Admin
- Manage Fees
- Manage Complaints
- Manage Events
- View Dashboard Analytics

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas
- **Deployment:** Vercel (Frontend), Render (Backend)

---

## 🚀 Run Locally

```bash
# Clone repository
git clone https://github.com/sadiafathima24/campus-os.git

# Backend
cd server
npm install
npm start

# Frontend
cd client
npm install
npm run dev
```

---

## 📌 Note

The application is deployed using **Vercel** (Frontend) and **Render** (Backend).

Since Render's free tier uses **ephemeral storage**, uploaded files are not permanently stored after server restarts. In a production environment, this would typically be replaced with cloud storage such as AWS S3 or Cloudinary.
